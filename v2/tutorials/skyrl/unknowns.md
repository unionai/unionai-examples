# Unknowns — what the SDK source cannot tell us

Each item names the owner (SDK vs backend) and the cheapest experiment. Experiment ids refer to
[experiments.md](./experiments.md).

| # | Unknown | Why it matters | Owner | Cheapest experiment |
|---|---|---|---|---|
| 1 | Are in-flight child actions **reaped or orphaned** when a parent pod is SIGKILLed? The SDK only aborts children on `asyncio.CancelledError` inside a live parent (`_controller.py:288-292`); run-level abort cascades backend-side (`_core.py:504-507`). | Orphaned trials keep burning sandbox $ after a driver crash; reaped ones must be re-run on the retry. | backend (leasor / actions) | E2 variant: parent spawns 5 long children, `os._exit(137)` on attempt 0; watch children's phases across the retry. |
| 2 | **Per-action dispatch latency and sustained launch rate** on a reusable pool. No numbers exist in-tree (`examples/stress/*` are harnesses without recorded results). | Sets the minimum viable rollout unit for L2b/L3. | backend + reuse worker | **E1** |
| 3 | Server-side **cap on children per parent / per run**. Client has 1000 in-flight (`_F_P_CNC`), 100 QPS (`_F_MAX_QPS`); a server cap would surface as `FAILED_PRECONDITION` → backoff (`_core.py:516-522`). | Fully-async default is 768 concurrent generation workers. | backend | E1 at n=1000+ with `_F_P_CNC` raised; watch for `SlowDownError` retries in logs. |
| 4 | Does a Flyte retry of a Ray-plugin task get a **fresh RayCluster**? The plugin emits one attempt-agnostic `RayJob` (`plugins/ray/.../task.py:222-278`); IDL has no `backoffLimit`. | Respin cost per retry; whether attempt 2 inherits a wedged cluster. | backend (KubeRay integration) | **E3** — compare Ray node ids across attempts; attempt timestamps give respin cost. |
| 5 | Does `RayFunctionTask.pre()` run on the **head pod or a submitter pod**? `submissionMode` is absent from the IDL. | Where the SkyRL driver lives, and whether it can reach engines/actors the way `skyrl_entrypoint.remote` expects. | backend | **E3** — hostname / `RAY_HEAD_SERVICE_HOST` in the body. |
| 6 | Are apps **Knative** under the hood? Zero references in `src/flyte/`. | Per-replica addressing, scale-to-zero, request-timeout behavior for anything app-shaped. | backend | Deploy a 2-replica app; inspect `kubectl get ksvc` on the dataplane, or ask platform. Not needed for the current verdicts (L2 is "no" regardless). |
| 7 | What the **reuse worker** (`unionai-reuse`, out of tree) does when a task raises or hangs past `timeout` — recycle the process or leak the coroutine? SDK side, a raise is a normal `error.pb` upload and the process survives (`taskrunner.py:117-131`). | A hung trial coroutine occupying a warm replica slot forever = silent capacity loss. | reuse worker | E1 variant: one child sleeps past `timeout=30s` on a `concurrency=1` pool; see whether the replica is reused afterwards. |
| 8 | Do checkpoints (`prevCheckpointPrefix`) carry across **`rerun(recover=True)`** for re-executed actions? `_run.py` never touches checkpoint paths. | Whether the trainer's `flyte.ctx().checkpoint` state survives a recover, or only a same-run retry. | backend | Run `examples/checkpoint/generic_data_checkpoint.py`, fail it, `flyte rerun --recover`, check `prev_exists()`. |
| 9 | **Volume fork/mount cost** for a world-sized filesystem vs a same-sized blob download; cluster has the FUSE device plugin? | Sandbox shape #2 (world data on a `Volume`). | plugin + cluster | **E5** |
| 10 | Trial pod → **vLLM router reachability** from a Flyte task pod on the same cluster as a KubeRay cluster (service DNS? pod IP? network policy?). | L3 / trial-as-action needs HTTP to the router. | cluster networking | Ray-plugin task publishes head pod IP (pattern in `examples/plugins/ray_existing_cluster.py`); a plain task curls it. |
| 11 | **SkyRL driver inside a Flyte task process.** `main_base.py` runs the loop as `@ray.remote skyrl_entrypoint`; a `FlyteGenerator` needs the Flyte controller, which lives in the task process. | Whether a subclassed `BasePPOExp` can run the loop in-process without losing anything. | SkyRL (user code) | Read `main_base.py::main`; prototype against `FullyAsyncTrainerSim`. |
